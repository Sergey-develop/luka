# CoinW Football Challenge

Игра для вертикальной сенсорной стойки 49″. Целевое разрешение — 1080×1920. Используйте Node.js 22.

## Запуск

```powershell
npm ci
npm run dev
```

Откройте локальный URL Vite. Для проверки выполните `npm test`, `npx playwright install chromium` и `npm run test:e2e`.

## Киоск Windows

```powershell
npm run build
npm run kiosk:serve
```

Сервер раздаёт производственную сборку локально. Откройте её установленным Chrome, указав путь к программе при необходимости:

```powershell
chrome.exe --kiosk http://127.0.0.1:4173/
```

Для автозапуска настройте в планировщике Windows запуск сервера при входе пользователя с рабочей папкой проекта и повторным запуском при сбое. Настройте запуск браузера на том же URL после запуска сервера. Используйте постоянный профиль браузера и один адрес, чтобы браузер сохранил историю. Страница после перезапуска открывается на стартовом экране. Сервер пишет в консоль адрес запуска и ошибки, приложение сообщает об ошибках хранения и рейтинга в консоли браузера.

## Настройки игры

В `src/config/game.ts` настраиваются границы ворот, порог и сила свайпа, скорость перемещения и задержки реакции вратаря, а также таймеры. После пяти валидных ударов игра показывает результат 12 секунд. Предупреждение перед игрой появляется через 10 секунд бездействия, возврат на старт — через 15. В режиме ожидания удара предупреждение появляется через 15 секунд, серия отменяется через 20.

Дневной рейтинг использует календарный день Дубая и лучший результат каждого участника. История сохраняется при смене дня. Серии из прежней версии с тремя ударами остаются в истории. В рейтинге отображаются только законченные серии из пяти ударов. Рейтинг показывает маскированный UID или никнейм. Email проверяется локально и не сохраняется.

Локальная история хранится в `localStorage` на этой стойке под ключом `coinw-football-results-v1`. При подготовке выгрузки оператор может открыть панель Application → Local Storage в DevTools браузера и скопировать значение этого ключа в JSON. В истории содержатся исходные UID.

Для приёмки заказчик подтверждает длительность предупреждения и экрана результата, ежедневное отображение рейтинга и финальные настройки жеста на реальном оборудовании. Текст согласия на обработку данных добавляется после предоставления заказчиком. Интеграция с CoinW API и отправка результатов по email требуют отдельного согласования.

## Звук

Звуки доступны после первого действия. Фон — минутная петля записи матча на стадионе De Kuip, с приглушёнными всплесками и плавным стыком. Он играет только во время матча (включая обратный отсчёт), в меню и на экранах результата и рейтинга его нет. Гол сопровождается отдельной записью футбольной толпы, промах — фрагментом предоставленного аудио. Обе реакции выровнены примерно до −20 LUFS с учётом огибающей воспроизведения и имеют одинаковый коэффициент громкости. Удар и кнопки используют записи настоящих звуков вместо синтезированных тонов. Звук всегда включён после первого взаимодействия; переключателя и сохранённого отключения нет. При скрытии вкладки звук приостанавливается. Все аудиоданные входят в сборку и доступны без интернета. Источники и лицензии указаны в `public/audio-credits.txt` (в сборке — `/audio-credits.txt`).

## Управление ударом

Длина и скорость свайпа задают начальную скорость, направление задаёт горизонтальный угол, длина движения вверх — угол подъёма. Полёт рассчитывается с гравитацией 9,81 м/с² до плоскости ворот в 11 метрах; визуализация и подсчёт попадания используют одну траекторию. Слабый удар опускается ниже, сильный может пройти над перекладиной. Прицел ограничен игровой областью, а движение за её пределами не усиливает удар. Для клавиатуры используется стабильная длительность жеста 350 мс.


## GitHub Pages

Публичная демоверсия: https://sergey-develop.github.io/luka/

Изменения в `main` автоматически проходят тесты, собираются и публикуются через `.github/workflows/pages.yml`. Относительные пути ресурсов и hash-маршрутизация позволяют запускать игру из `/luka/`.

Рейтинг хранится локально в браузере каждого устройства; общего серверного рейтинга в демоверсии нет.

Переключатель ENG / RUS доступен на всех экранах. Выбор языка сохраняется в браузере и не сбрасывает введённые данные или текущую игру. Отсчёт 3–2–1 начинается после загрузки игрового поля.
